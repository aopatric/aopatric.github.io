Work

  • 2025.02 - 2025.08
    Undergraduate Researcher
    Solar-Lezama Group, MIT CSAIL
    A Benchmark for Spatial Understanding with Origami
    • Extended an existing Gymnasium MDP formulation of inverse origami for language model evaluation, writing tooling to automate benchmark generation from a curated set of 25 reusable target origami stored as .obj files. Acknowledged in the OrigamiBench writeup.
    • Established baseline shape-reconstruction performance by comparing MCTS, PPO, random walks, and evolutionary methods against the preliminary benchmark suite. Found strong correlation between performance drop and shape complexity in all approaches except random.
  • 2024.11 - 2025.02
    Undergraduate Researcher
    Camera Culture Group, MIT Media Lab
    SONAR Web: Real-Time Decentralized Learning Across Heterogeneous Edge Clients
    • Built cross-platform federated learning clients in Python (PyTorch) and JavaScript (TensorFlow.js). Leveraged a platform-agnostic config format and a universal JSON-based weight representation for framework-agnostic communication between heterogeneous peers.
    • Contributed to a WebRTC communication layer with a central-server handshake for session join and zero server involvement thereafter. Implemented chunked streaming weight transfer to share larger models between peers, bypassing WebRTC's 16MB data channel limit.
    • Validated cross-platform training and weight exchange across ring, mesh, toroidal, and Erdős-Rényi topologies with up to 12 peers, verifying gradient flow on MLP and CNN baselines over MNIST and CIFAR. Core components remain in the published system.
  • 2024.04 - 2024.08
    Undergraduate Researcher
    Edelman Lab, MIT IMES
    Masked Language Modeling for Genomics
    • Rebuilt data pipeline for DistilBERT fine-tuning on the 30M-sample CELLxGENE census dataset, writing custom collators for the transcriptomics format including both sharding and streaming to eliminate full-dataset memory pressure. Parallelized training with HF accelerate across 8+ GPUs on a Vast.ai instance, cutting epoch times from hours to minutes.
    • Built automation with WandB logging, allowing full experiment suites producing a collection of masked language modeling checkpoints, trained over vectors of concatenated phenotype labels and 500+ dimensional gene expression profiles. This formulation allowed a single model to perform classification, imputation, or both depending on the masking pattern; deployed a simple Streamlit interface for inference on user samples.

Projects

  • 2026.09 - Present
    Mechanistic Interpretability Testbed for Reward Hacking in Qwen3-4B
    Independent project (ongoing)
    • Extended the reproducible RL-induced reward hacking setup from ariahw/rl-rewardhacking for Qwen3-4B into an expandable testbed for mechanistic interpretability tools to study how reward hacking emerges in language models; implemented activation caching over rollouts via PyTorch forward hooks.
    • Still ongoing, and serves as a live testbed for trying out different mechanistic interpretability tools as I learn the landscape of the field ahead of grad school.
    • Building in stages: training linear probes on residual-stream activations to detect hacking vs. honest behavior at prompt time, and implementing activation patching to localize the responsible components and steering along probe directions to suppress hacking.
  • 2025.09 - 2026
    Finding an Edge of Stability for LLM Post-Training
    Course project, MIT 6.7960 Deep Learning (Fall 2025; revisited 2026)
    • Built a PyTorch/HF pipeline tracking global and batch sharpness (top Hessian eigenvalues via PyHessian) while fine-tuning Pythia models (70M to 1.4B) on Alpaca with full SFT and LoRA, searching for the Edge of Stability (EoS) in LLM post-training. Initial experiments found no EoS signature.
    • Revisited the project in 2026 after finding flaws in the original measurements: rebuilt curvature tooling GPU-native in PyTorch (Hessian-vector products, batched power iteration) for a ~5× speedup over the CPU-bound original; validated against exact Hessians on small models, reference-library solvers, and invariant checks.
    • Established a positive control with the new tooling, confirming existing EoS results, but did not observe EoS in the full-scale experimental runs (up to 1.4B): sharpness built up early, then slowly tapered off instead of settling at a stability threshold, and near-degenerate top eigenvalues made single-eigenvalue estimates unstable.
